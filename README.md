# Melfa Kinematics

Repositorio de estudio para organizar y modularizar un notebook académico de cinemática de un robot industrial MELFA de 6 GDL.

## Objetivos

- Aprender Git y GitHub
- Organizar un proyecto técnico
- Separar notebooks y código reusable
- Crear módulos reutilizables
- Validar funciones matemáticas básicas

## Estructura inicial

- docs/: documentación del caso de estudio
- notebooks/: notebooks originales y exploratorios
- src/: código reusable del proyecto
