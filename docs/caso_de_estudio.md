# Caso de estudio

Este proyecto toma un notebook académico de cinemática de un robot MELFA y lo convierte progresivamente en un repositorio organizado y extensible.

La meta no es solo guardar archivos, sino aprender:

- control de versiones con Git,
- publicación en GitHub,
- modularización,
- ambientes virtuales,
- validación básica de funciones,
- organización de proyectos técnicos.
